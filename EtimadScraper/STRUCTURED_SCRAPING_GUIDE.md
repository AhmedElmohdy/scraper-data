## ?? Extraction Strategies

The service now uses **4 different strategies** to ensure maximum data extraction:

### Strategy 1: Table Structure
Extracts from HTML tables (most common in Etimad):

```html
<table>
  <tr>
    <td>??? ????????</td>
    <td>42441</td>
  </tr>
</table>
```

### Strategy 2: Bootstrap Grid Layout
Extracts from div.row/div.col structure:

```html
<div class="row">
  <div class="col-md-6">????? ????????</div>
  <div class="col-md-6">????? ????? ?????????</div>
</div>
```

### Strategy 3: Label-Input Pairs
Follows label ? input/span associations:

```html
<label for="tenderName">??? ????????</label>
<input id="tenderName" value="???? ?????..." />
```

### Strategy 4: Definition Lists
Extracts from dt/dd pairs:

```html
<dl>
  <dt>????? ?????</dt>
  <dd>16/10/1447</dd>
</dl>
```

## ?? Fallback Mechanism

If scraping fails, the service falls back to cached database data:

```csharp
// 1. Try scraping
var tenderDetails = await ScrapeTenderFromWebAsync(tenderId);

// 2. If fails, try cache
if (!tenderDetails.IsSuccess)
{
    var cached = await GetCachedTenderDetailsAsync(tenderId);
    if (cached != null) return cached;
}

// 3. Return error
return tenderDetails;
```

### Implementing Database Cache

```csharp
private async Task<TenderDetailsDto?> GetCachedTenderDetailsAsync(string tenderId)
{
    using var dbContext = _dbContextFactory.CreateDbContext();
    var cached = await dbContext.TenderDetails
        .Where(t => t.TenderId == tenderId)
        .OrderByDescending(t => t.ScrapedAt)
        .FirstOrDefaultAsync();
    
    if (cached != null)
    {
        cached.DataSource = "Cached";
        return cached;
    }
    return null;
}
```
